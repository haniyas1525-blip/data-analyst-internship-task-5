# Titanic Exploratory Data Analysis – Task 5

## Objective
To explore the Titanic dataset and identify important patterns, trends, relationships and anomalies using Python.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Dataset information
- Statistical analysis
- Missing value analysis
- Duplicate checking
- Survival analysis
- Gender-wise survival analysis
- Passenger class analysis
- Age and fare distributions
- Boxplots
- Scatterplot
- Correlation heatmap
- Pairplot

## Key Findings
1. Female passengers had better survival chances than male passengers.
2. Higher passenger classes generally had better survival rates.
3. Fare showed a relationship with passenger class and survival.
4. Age had a wide distribution among passengers.
5. Some numerical variables contained outliers.
6. Missing values were identified and handled.

## Conclusion
Exploratory Data Analysis helped identify important patterns and factors related to passenger survival in the Titanic dataset.
